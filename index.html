Ascon-AEAD128 hardware implementation

Verilog · NIST SP 800-232 · in progress

A Verilog RTL implementation of Ascon, the lightweight authenticated encryption standard selected by NIST. The design covers the permutation core and the AEAD128 datapath, including handling of variable-length associated data — the part where the control logic gets interesting.

Verified in simulation against the standard's test vectors using Questa Advanced Simulator.
