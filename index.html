Ascon-AEAD128 cryptographic core

SystemVerilog RTL & UVM verification · NIST SP 800-232 · Personal project, 2026

  • Full SystemVerilog implementation of Ascon-AEAD128: a 320-bit sponge datapath with authenticated encryption and decryption, computing one permutation round per clock from a single shared permutation instance for area efficiency.
  • Verified against all 1089 NIST known-answer-test vectors — encryption, decryption and tag rejection on corrupted tags — then closed to 100% functional coverage in a self-built UVM environment (driver, pin-level monitor, scoreboard, coverage subscriber).
  • Vivado synthesis for AMD Artix-7: 1686 LUTs, 1573 flip-flops, no BRAM or DSP inference, 182 MHz Fmax (≈2.1 Gbit/s).

Memory-optimised FPGA stencil accelerator

HLS on AMD Alveo & Zynq · Master's thesis, 2024–2025

  • Designed a memory-optimised dataflow accelerator for horizontal-diffusion stencil computation, inspired by the SODA framework: minimising the on-chip reuse buffer required for full data reuse, and so overcoming the kernel's memory-bound limits.
  • Built an end-to-end automated flow around the design — HLS code generation → synthesis → implementation → reporting — targeting AMD Alveo and Zynq FPGAs with Vitis HLS, Vivado and custom Python scripting.
  • Explored the design space across spatial parallelism, fixed-point bit-width precision and resource constraints, showing that a well-configured fixed-point implementation gives the optimal performance–efficiency balance.
